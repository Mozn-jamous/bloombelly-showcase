## Capture Guidelines

- **Status bar:** clean (full battery, no notifications)
- **Frame the device:** use [deviceframes.com](https://deviceframes.com) or [mockup.photos](https://mockup.photos) for polish
- **Realistic data:** no `Lorem Ipsum`, no test values like "abc123"
- **Variety:** include light mode + dark mode + Arabic + English samples
- **Privacy:** scrub any real personal data
